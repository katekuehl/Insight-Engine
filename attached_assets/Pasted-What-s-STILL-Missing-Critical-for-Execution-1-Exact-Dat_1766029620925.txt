3. Validation Rules (Beyond Just Types)

For metricsAnalytics:
- sessions >= 0
- bounce_rate between 0-100
- organic_sessions + direct_sessions + paid_sessions + social_sessions + referral_sessions + email_sessions = sessions
- desktop_sessions + mobile_sessions + tablet_sessions = sessions
- If goal_completions > 0, then goal_conversion_rate > 0

For metricsAds:
- spend >= 0
- conversions >= 0
- If conversions > 0, then cpa = spend / conversions
- impressions >= clicks
- If clicks > 0, then ctr = clicks / impressions * 100

For metricsCrm:
- total_leads >= mql_count >= sql_count >= opportunities_created
- closed_won + closed_lost + open_opportunities = opportunities_created
- If closed_won + closed_lost > 0, then win_rate = closed_won / (closed_won + closed_lost) * 100
- revenue metrics should align with deal counts

For metricsEmail:
- total_subscribers >= new_subscribers
- total_emails_sent >= delivered + bounced
- delivered <= total_emails_sent
- open_rate <= 100, click_rate <= 100
